# 01-fixed. «Привет, мир!» так, как работало бы на железе

Работа над ошибками к [первой статье](https://habr.com/ru/articles/1065554/).

В опубликованной версии программа писала байты в регистр передатчика,
не спрашивая, свободен ли он. В эмуляторе это проходит, на железе нет.
На это указал читатель в комментариях, и он прав.

Здесь исправленная версия. Отличий два.

**UART настраивается.** Задаются делитель скорости и формат кадра 8N1.
В эмуляторе оно работало и без этого.

**Перед каждым байтом ждём освобождения передатчика.** Три инструкции:
читаем регистр состояния линии LSR по смещению 5, проверяем бит 5
(THRE, Transmitter Holding Register Empty), крутимся, пока он снят.

```asm
wait_thre:
    lbu     t3, UART_LSR(t0)
    andi    t3, t3, LSR_THRE
    beqz    t3, wait_thre
```

Заодно адреса регистров вынесены в именованные константы: голое
шестнадцатеричное число в коде справедливо ругали.

## Почему разницу не было видно

Стоковый QEMU принимает байт мгновенно и никогда не сообщает, что
передатчик занят. Бит THRE в нём не снимается ни на такт, поэтому
цикл ожидания не делает ни одного оборота, а код без ожидания работает
как ни в чём не бывало. Проверить себя внутри эмулятора было нечем.

Чтобы это стало видно, пришлось починить сам эмулятор. Патч лежит
в `../01-hello-lsr-probe/uart-pacing.patch`, разбор в `NOTES.md` рядом
с ним.

## Что показывает пропатченный QEMU

Строка «Привет, мир!», 22 байта вместе с переводом строки.

| Версия программы | Флаг выключен | Флаг включён |
|---|---|---|
| Из первой статьи | 22 байта, всё верно | **1 байт**, `0xD0` |
| Исправленная, из этого каталога | 22 байта | 22 байта |

Один байт `0xD0` это первая половина двухбайтовой буквы «П». Всё
остальное затёрлось, потому что процессор пишет быстрее, чем линия
успевает отдавать.

## Сборка и запуск

Как в первой статье. Файл `boot-test.s` нужен только для замеров: это
та же программа плюс пауза и штатное завершение эмулятора, без них
backend не успевает сбросить буфер и результат замера врёт.

```
make
make run
```

С пропатченным QEMU и включённым флагом:

```
qemu-system-riscv32 -global serial-mm.xmit-pacing=on \
    -machine virt -nographic -bios none -kernel hello.elf
```
